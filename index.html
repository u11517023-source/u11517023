05 — Reflection

What I Think.

一開始接觸 HTML 與 CSS 時，我覺得程式碼很陌生， 也不太容易想像每一行程式最後會變成什麼樣子。 但在實際修改與練習之後，我開始慢慢理解 程式碼和網頁畫面之間的關係。

對我來說，目前最大的收穫不只是記住程式碼， 而是開始知道如何透過不同的 HTML 與 CSS 元素去完成自己想要的網頁效果。 未來也希望能將這些基礎能力運用在更多作品上。
